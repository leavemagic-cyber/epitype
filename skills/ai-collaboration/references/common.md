# 共用協作流程

依當前授權續做；一般聊天或單 AI 工作不自動升成跨 AI。各模式只讀相關細節，已讀且未變就重用。

- **材料**：固定工作目錄、版本／確切 diff、有效要求與例外、驗收。給相關證據、系統關係及鄰近檔案路徑，讓對方能查完整上下文；不重播無關歷史。AI 整理標明分類；原話只在實質歧義、衝突或明確稽核時回查，不是開工門檻。
- **責任**：依指定名單及現行分工選作者、非作者審查者；預設一位非作者審查。lead 查證、整合與交付；Codex 是正式 repo 唯一寫手，其他席交回有界的分析、patch 或測試，獲授權的協作作者在隔離範圍實作；不自動另派子代理。
- **判斷**：初輪各自保存立場再看他人答案，不附和、不製造缺陷。發現須有情境、影響、path:line、證據、修法及未查範圍；作者逐項接受或附證據反駁。lead 親查重要程式／來源／測試，票數和 APPROVE 不代替證據。
- **收斂**：真缺陷未解就修並審受影響處，無缺陷就結束；風格建議同輪處理，不固定加輪。做法連敗兩次就診斷換法；可解的爭議自己解，不因輪數問 owner。額外模型依授權選最強未參與者；只有真正缺授權、owner 專屬取捨或關鍵事實才提問。
- **交付**：沿用有效檢查，按需先做機械檢查，不固定增派 verifier。保存實際參與者／模型、版本、結論、重大分歧和驗證邊界；只署真實簽名。依授權提交明確路徑；合併、啟用另查效果，不固定合併到別的專案。收尾只清理自己的資源。

共用檔就是狀態機。沿用現有標記家族，或 `===CODEX_IMPL_U<N>_DONE===`、`===CLAUDE_REVIEW_U<N>_DONE===`、`===CODEX_REVIEW_<N>_DONE===`。寫完標記後等對方回應；這輪工作完成或主持者收尾就停，沒有工作時不空轉。

省 token 靠短交接、範圍明確的派工包、拆開審查與精簡監看，不重送整份正本或 transcript。
