# 按需執行補充

- `python -B <seats.py> models` 會查當前候選，可能連線；重用有效結果，不每輪重查。
- `python -B <seats.py> quota [--agy-usage <專案工具>]` 在用量需要確認時才跑。Grok 無本機 reader；`ping --cwd <目錄> --seat <seat:model:effort>` 會真正發請求，只在狀態不明時用。
- Antigravity 作 Gemini 獨立席時，只選當前 Gemini 家族；其他公司模型不算新的獨立公司。帳號切換只在兩次執行間按授權處理。保留 Antigravity 優先於 Grok 的偏好，不覆蓋指定名單及能力要求。
- 少席可完成的工作繼續，列缺誰、原因與已知恢復時間；缺關鍵證據就保存進度並做獨立工作。不因重置一天內自設全面停工，也不改用停用的付費點數。
- `<tag>_status.json` 記錄當次名單、各席結果與來源檢查。每席 receipt 綁實際答案；重啟可補未完成席，同題有效答案不重跑。同一輪只允許一個寫入者，OS 在崩潰後自動釋放鎖，不刪別人的鎖或程序。
- 未由 `--input` 涵蓋的 dirty 資料不快取但可繼續；非 Git 只驗明列檔案，外部網路資料不快取。這些狀態不冒稱全專案內容一致。資料在執行中變更，該輪結果不再用作完成證據。
- runner 返回值：`0` 執行完成、`1` 席位失敗／來源變動、`2` 組題不完整或缺席、`3` 該輪已有寫入者。檢查狀態與產物，不能只看程序結束。
- `bundle` 對缺席明標 PARTIAL；可用 `--allow-partial` 取得明標材料，仍不算全員完成。缺範本欄位不覆蓋舊有效題目。舊手工回答無 receipt 會標 UNATTESTED，仍可作參考，不要求追回原話。
- 唯讀參數、提示、狀態與 receipt 都不是答案正確性的保證；lead 親查實際來源、差異、必要測試及未查範圍，只有查到的部分算驗證。
