# Epitype Essentials privacy policy

Epitype Essentials is a set of three Markdown skills. Installing this plugin does not run a program, create a hook, or connect to an external service. The plugin itself does not collect, transmit, or retain personal data. It does not access Claude memory, chat history, conversation summaries, or uploaded files.

When you ask Claude to perform a project task, Claude may use tools already available in your own Claude environment. Those tools and Claude's handling of your conversation follow the policies and permissions of the services you use. This plugin adds no tool permissions or remote endpoint.

The separate Epitype Python package has its own local functionality and is not installed by this plugin. For questions about this plugin, use the [Epitype issue tracker](https://github.com/leavemagic-cyber/epitype/issues).
